# Монитор предложений автомобилей

Один почасовой GitHub Actions workflow последовательно проверяет два независимых
целевых автомобиля. Он сохраняет наблюдения и очередь уведомлений до отправки в
Telegram, поэтому результат здоровой цели не теряется, если у другой площадки
есть только разрыв источника.

## Цели и критерии

### Volkswagen Teramont Pro 2026

Ищется Volkswagen Teramont Pro модельного года 2026 с чёрным кузовом и чёрным
салоном, DCC, комплектацией Peak/Summit или подтверждённым эквивалентом,
физическим наличием у продавца и пробегом от 0 до **1 000 км включительно**.

### Range Rover L460 D350 Autobiography 2026

Ищется только полноразмерный Range Rover **L460** 2026 модельного года в SWB
или LWB. Обязательны D350 (либо однозначное сочетание 3.0 diesel,
257–258 kW / 349–351 hp), Autobiography, чёрный кузов и чёрный салон, физическое
наличие и пробег от 0 до **1 000 км включительно**.

Нужна явная заводская Rear Seat Entertainment: две задние пассажирские экрана.
Нештатные планшеты, съёмные экраны в подголовниках и явное отсутствие RSE не
подходят. Исключаются Range Rover Sport, Velar, Evoque и другие модели Land
Rover. Для Европы дополнительно нужен подтверждённый левый руль; правый руль
исключается. Неизвестная сторона руля в Европе остаётся кандидатом, но не
создаёт релевантное уведомление.

## Рынки, данные и пороги

Источники Range Rover сгруппированы по физическому местонахождению автомобиля:

- Россия: Auto.ru, Drom, Avito;
- Кыргызстан: Mashina.kg;
- Грузия: MyAuto, публичный склад Jaguar Land Rover Georgia, AutoBridge;
- Европа: mobile.de, AutoScout24.

Цена всегда хранится в исходной валюте площадки. Конвертация валют и сравнение
цен разных валют не выполняются. Уведомление о снижении подтверждённой
безусловной цены создаётся только при достижении одного из пяти порогов:

| Цель | Валюта | Минимальное снижение |
|---|---|---:|
| Teramont Pro | RUB | 50 000 RUB |
| Range Rover | RUB | 100 000 RUB |
| Range Rover | EUR | 1 000 EUR |
| Range Rover | GEL | 3 000 GEL |
| Range Rover | KGS | 100 000 KGS |

Цена с кредитом, trade-in, страхованием или другим условием хранится отдельно и
не считается подтверждённой безусловной ценой. Валюта без порога сохраняется в
наблюдении, но не создаёт событие снижения цены.

Правдоподобное объявление с неполным подтверждением — `candidate`; отсутствующее
свидетельство — `unknown`, а не отрицательный факт. CAPTCHA, 403/429, ошибка
сети, неожиданно пустая выдача или недоступная карточка — это привязанный к
источнику `source_gap`, а не нулевое число предложений и не подтверждение снятия
с продажи. Кандидаты и source gaps сохраняются. Кандидаты не создают срочное
событие, но могут попасть в отдельный раздел почасового ценового отчёта.

## Состояние и доставка

Ветка `monitor-state` намеренно имеет асимметричную структуру:

- корневые `state.json`, `history.jsonl`, `pending-events.json` и
  `price-digest.json` — состояние и последний ценовой срез Teramont Pro;
- `range-rover-d350/state.json`, `range-rover-d350/history.jsonl` и
  `range-rover-d350/pending-events.json`, а также
  `range-rover-d350/price-digest.json` — независимое состояние Range Rover.

Не переносите и не переименовывайте корневые файлы при добавлении Range Rover:
это сохраняет историю Teramont и не воспроизводит старые события. Первый запуск
создаёт каталог `range-rover-d350/` сам. При rollback он может остаться для
аудита; удаление состояния — отдельное необратимое действие.

Один сериализованный workflow запускает Teramont, затем Range Rover, после обеих
сборок один раз сохраняет состояние, затем последовательно доставляет очереди и
ещё раз сохраняет статус доставки. Если одна цель завершилась с source gaps,
другая всё равно сохраняется и получает попытку доставки; общий job завершается
ошибкой только после этой последовательности.

После каждого успешного почасового или ручного сбора Telegram отправляет до
трёх карточек автомобилей для каждой цели. Сначала идут самые дешёвые полностью
релевантные предложения, которые физически находятся в России и имеют
подтверждённую безусловную цену в RUB. Повтор одного VIN не показывается
дважды. Если подтверждённых предложений меньше трёх, оставшиеся места занимают
ближайшие кандидаты из России с положительной ценой из объявления и без явного
признака продажи или отсутствия. У каждого кандидата перечислены параметры,
которые ещё требуют проверки.

Карточка содержит главное фото площадки, название, город и регион, год,
пробег, наличие, комплектацию, цвет кузова и салона, целевые характеристики
(DCC для Teramont; D350 и заводские пассажирские мониторы для Range Rover),
VIN, ЭПТС и коммерческий утильсбор при наличии этих данных, источник, цену и
прямую ссылку. Подтверждённая наличная цена подписана как `Цена за наличные`;
неподтверждённая рекламная цена — как `Цена из объявления — условия оплаты не
подтверждены`. Если Telegram не может загрузить фото или площадка его не
предоставила, отправляется полноценная текстовая карточка со ссылкой. Если нет
даже кандидатов с ценой, бот отправляет диагностическое сообщение без машин.

Ценовой отчёт использует только объявления, полученные в текущем сборе с
доступных источников; старое наблюдение с временно недоступной площадки не
выдаётся за актуальное наличие. При полном сбое источников отчёт этой цели не
отправляется, но здоровая цель продолжает работу.

Отдельно Telegram сохраняет срочные уведомления `new_relevant`, `price_drop`,
`became_available`, `critical_confirmation` и `removed_or_sold`. Неудачная
доставка срочного события оставляет его в очереди для следующего запуска.

## Настройка GitHub

### 1. Разрешить запись состояния

Откройте репозиторий → **Settings → Actions → General → Workflow permissions**
и выберите **Read and write permissions**. Workflow использует только
`contents: write`: это минимальное разрешение для записи ветки `monitor-state`,
а кодовая ветка автоматически не меняется.

### 2. Добавить ровно два GitHub Secrets

Откройте **Settings → Secrets and variables → Actions → New repository secret**:

| Secret | Содержимое |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от BotFather |
| `TELEGRAM_CHAT_ID` | числовой ID личного чата, группы или канала |

Это единственные Secrets для workflow: не добавляйте других секретов и не
помещайте токены в конфигурацию, README, команды Git или состояние. Для группы
или канала дайте боту право публикации; для личного чата сначала отправьте боту
хотя бы одно сообщение.

### 3. Первый запуск и расписание

После попадания кода в основную ветку откройте **Actions → Vehicle marketplace
monitor → Run workflow**. Первый успешный запуск создаст `monitor-state`.

Расписание — каждый час на 17-й минуте UTC (`17 * * * *`). GitHub запускает
расписания best-effort: при высокой нагрузке запуск может задержаться или редко
быть пропущен. Локальный commit или наличие workflow в отдельной ветке **не запускает мониторинг**; он не активирует расписание и не меняет настройки GitHub.

Job ограничен 140 минутами. Это покрывает консервативную верхнюю границу для
14 последовательных источников: 14 поисковых запросов и до 290 карточек при
тайм-ауте 25 секунд на запрос, межкарточных задержках и дополнительном запасе на
тесты и сохранение состояния. Источники намеренно не распараллеливаются, чтобы
не усиливать rate limit и не создавать конкурентные записи состояния.

## Локальная проверка

Требуется Python 3.12 или новее. В PowerShell выполните:

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -t . -v
python -m teramont_monitor smoke --config config/sources.json --target config/targets/teramont-pro-2026.json --dry-run
python -m teramont_monitor smoke --config config/range-rover-sources.json --target config/targets/range-rover-l460-d350-autobiography-2026.json --dry-run
```

`smoke` только читает живые публичные страницы: он не пишет состояние и не
отправляет Telegram. Блокированные или недоступные источники выводятся как
`source_gap`, а не маскируются под пустой рынок.

## Изменение источников и диагностика

Teramont использует `config/sources.json`, Range Rover —
`config/range-rover-sources.json`; профили целей находятся в `config/targets/`.
При изменении разметки меняйте только нужную конфигурацию/адаптер и минимальный
тестовый пример. Не добавляйте обход CAPTCHA, авторизацию, прокси или новые
секреты без отдельного решения владельца.

В состоянии и репозитории не хранятся токены, cookies, исходные HTML-страницы,
телефоны, email или другие контакты продавцов. Диагностический artifact при
ошибке содержит только два очищенных JSON-итога сборки и хранится 14 дней.
